# Outils récupérés de la seconde copie Smolcoder

Ce dossier conserve les scripts et configurations présents dans la copie
`C:\Users\DELL\.smolcoder` mais absents du dépôt principal.

Le coeur officiel de Smolcoder reste à la racine du projet (`src/`, `desktop/`,
`test/`). Ces outils sont conservés pour éviter toute perte de travail et ne
sont pas exécutés automatiquement par le build principal.

Les configurations MCP réellement utilisées sont fusionnées par Smolcoder
depuis `.smol/mcp.json` et `~/.smolcoder/mcp.json`. Le fichier `mcp.json` ici
est une copie historique de la seconde configuration.
